La programmation compétitive

Résoudre des problèmes algorithmiques, seul ou en équipe, sous contrainte de temps. Trois formats principaux:

  • Casse-têtes jugés automatiquement — Kattis, Codeforces, LeetCode, AtCoder
  • Code golf — le programme le plus court possible
  • Affrontement de programmes — Core War, Battlecode, Leek Wars

Compétitions

  • ICPC — équipes de 3, régionale en mars, finales mondiales
  • CS Games — compétition interuniversitaire québécoise
  • Autres — Advent of Code, Hash Code, Hacker Cup

Pourquoi nous rejoindre?

  • Des casse-têtes stimulants entre passionnés
  • Préparation aux concours et entrevues techniques
  • Nouvelles techniques et algorithmes
  • Tous les niveaux, du débutant à l'expert

Activités

Rencontres hebdomadaires, préparation aux concours, mock contests, code reviews. Le langage n'a pas d'importance: C++, Python, Java et bien d'autres.
